# 担当継続1年の昇給

給与集計時にスタッフと利用者の組み合わせごとに判定する。1年到達月の翌月分から運営スタッフ4,000円、他スタッフ3,500円とする。例: 2026-09-15に担当開始なら2027-10から。本人紹介は現在単価を維持し、上乗せしない。毎年500円ずつ増える処理ではない。

「担当継続昇給」シートで担当開始日、給与区分、本人紹介、運用開始月を確認し、有効をチェックした担当だけが対象。運用開始月（YYYY-MM）は新給与体系へ手動切替した月以降を設定する。実際の昇給は1年到達の翌月と運用開始月の遅い方から。

11月分（12月支給）の運営スタッフの体系変更は手動のまま。既存担当の開始日を推測して登録・有効化しない。現在の支払済み月より前へ遡って運用開始月を設定しない。空の設定シートを作るだけでは現在単価は変わらない。

給与単価履歴の月別単価を取得してから、この昇給条件を適用する。履歴・マスタは書き換えず、給与集計時に対象月の単価を計算する。本人紹介・設定なし・無効なら従来単価を維持し、既に昇給後単価より高い場合も減額しない。新体系の通常単価未満なら自動で体系変更せずエラーにする。

開始日の中断・再開条件は個別に確認する。過去の判定に影響する設定の上書きや削除はしない。年次自動処理は基本給与単価のみで、交通費・利用者料金・振込実行は変更しない。
