## LIFFモード

GitHub Pagesの `index.html` は、URLパラメータ `mode` で画面を切り替える。

- `?mode=staff`: スタッフ用画面。担当利用者、訪問予定、開始・終了、予定変更、キャンセル、スタッフフォルダを表示する。
- `?mode=user`: 利用者用画面。本人に紐づく予定と予定外実績を確認する。
- `?mode=register`: 新規利用者登録LIFF。LINE情報を保存し、利用申請フォームへ進む。
- `?mode=staff-register`: スタッフ登録LIFF。LINE情報を保存し、スタッフ登録フォームへ進む。
- `?mode=important`: 重要事項説明LIFF。登録済みスタッフまたは紐づき済み利用者だけ確認できる。
- `?mode=admin`: 管理者LIFF。データ整備、紐づけ確認、代理表示テスト、スタッフ利用者マスタの紐づけ保存・解除を行う。
- `?mode=qr`: 公式LINE友だち追加用QR表示。

## 管理者LIFF

管理者LIFFは `管理者マスタ` の `LIFF用LINEユーザーID`、またはコード内の固定管理者IDで利用可否を判定する。

できること:

- 未反映のLINEユーザー候補、紐づけ件数、要確認件数、未紐づけ利用者を確認する。
- `一括実行`、`利用者アンケート取込`、`LINE情報を反映`、`ID列を整える`、`LIFF表示更新`、`回数券更新`、`スタッフ登録トリガー設定` を画面から実行する。
- スタッフまたは利用者の代理表示を読み込む。代理表示は表示確認専用で、開始・終了・変更・キャンセルは実行しない。
- `スタッフ利用者マスタ` の紐づけを追加・更新・解除する。保存・解除後はLIFF表示用マスタも更新される。

注意:

- 管理者LIFFからの一括実行、LIFF表示更新、回数券更新、スタッフ登録トリガー設定、紐づけ保存、紐づけ解除はスプレッドシートやトリガー設定を書き換える。
- 実行前に、対象スタッフ、対象利用者、実行目的、LIFF表示への影響を確認する。
- スタッフ登録トリガー設定は、フォーム回答後のスタッフマスタ取込・フォルダ作成/共有・ログ記録を自動化する。共有通知メールが届く可能性があるため、必要時だけ実行する。
- 管理者未登録表示が出る場合は、表示されたLIFF用LINEユーザーIDを `管理者マスタ` に登録する。

`✅ データ整備を一括実行` は、次の処理をまとめて実行する。

- スタッフID、利用者ID、紹介者ID、スタッフ利用者マスタID列の整備
- スタッフ登録フォーム回答のスタッフマスタ取込
- 利用者アンケート回答の利用者マスタ取込
- `LINEユーザー一覧` の紐づけ候補更新
- LINE情報のスタッフマスタ・利用者マスタ反映
- `紹介者マスタ` と `紹介管理` の作成・更新
- 振込先登録状況の更新
- LIFF表示用マスタの更新

紹介者管理の実装:

- `紹介者マスタ`: `紹介者ID`、紹介者名、所属、職種、LINE情報、紹介料対象、紹介料支払状況、状態、メモを管理する。
- `紹介管理`: 紹介日、紹介者、利用者、紹介元種別、利用開始日、紹介料対象、紹介料支払状況、状態、メモを管理する。
- 利用者マスタに紹介者名がある場合、紹介者マスタと照合し、未登録なら `紹介者確認` として残す。

## 回数券・GMO入出金CSV

回数券管理は、`GMO入出金CSV貼付`、`入出金明細`、`訪問実績`、`利用者マスタ`、`回数券基準` をもとに更新する。

- `🎫 回数券を更新` は、貼り付け済みGMO入出金CSVを取り込み、回数券管理を更新する。
- 集計開始日は `2026/04/20`。
- 標準の回数券単価は `7,500円`。利用者マスタ側に単価があればそれを使う。
- `回数券基準` がある利用者は、基準日・基準残数以降で集計する。
- `回数券管理` では、回数券残数、当月利用回数、当月入金回数、未入金額、不足額、直近入金日などを確認する。

注意:

- GMO入出金CSVの貼付・取込は入金確認や請求判断に関わるため、実行前に対象CSVと対象期間を確認する。
- `GMO入出金CSV貼付` が空、またはシートがない場合は更新できない。
