# 作業ルール

## 作業前の提示

コード、設定、外部サービスに触る前に、以下をわかりやすく提示する。

- これから何を変更するか
- 変更対象ファイル
- 実行するコマンド
- デプロイ有無

## 明示許可が必要な操作

以下は、明示的な許可があるまで実行しない。

- スプレッドシート本体を変更する関数の実行
- Google Drive上のフォルダ作成
- Google Drive上のフォルダリンク更新
- GAS本番デプロイ
- GitHubへのpush
- 本番データに影響する確認コマンド

## 変更のまとめ方

- コード全文は貼らず、必要な場合はファイルリンクで参照する。
- デプロイや確認は、クレジット消費を避けるため、できるだけまとめて行う。
- 手順として再利用する判断や注意点は、スキルまたはこの台帳に追記する。
