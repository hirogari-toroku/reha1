# 自費リハシステム プロジェクト台帳

このフォルダは、合同会社ひろがりの自費訪問リハビリテーション関連作業を横断して管理するための台帳です。

## 管理対象

- 重要事項説明書、説明動画、WordPressページ、同意フォーム
- LINE / LIFF / GAS / GitHub Pages
- 自費リハ管理スプレッドシート、スタッフマスタ、給与集計、振込CSV
- 管理者LIFF、スタッフ・利用者紐づけ、代理表示確認
- 回数券管理、GMO入出金CSV貼付、紹介者管理
- GMOあおぞらネット銀行 参照系API申請
- 作業手順として残すべき運用ルール

## 重要な方針

- 作業前には、変更内容、対象ファイル、実行コマンド、デプロイ有無を提示する。
- スプレッドシート、Drive、GAS、GitHubへの変更は慎重に扱う。
- Driveフォルダ作成、フォルダリンク更新、スプレッドシート本体変更、GAS本番反映は明示許可なしに実行しない。
- 管理者LIFFからの紐づけ保存・解除、一括データ整備、回数券更新もスプレッドシートを変更するため、実行前に目的と影響を確認する。
- 手順として再利用する内容は、`hirogari-operations` スキルまたはこの台帳に反映する。
