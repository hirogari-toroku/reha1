# 給与計算手順

## 目的

月末または給与処理時に、訪問実績から給与集計、給与明細PDF、GMO振込CSV、スタッフフォルダへの格納までを行う。

## 基本方針

- テスト利用者は給与計算対象外。
- 給与0円の明細は作成しない。
- スタッフフォルダと給与明細フォルダは同じ。
- 給与明細PDFは各スタッフフォルダへ入れる。
- GMO振込CSVは `GMO振り込みCSV確定` フォルダへ移動する。
- 回数券管理は給与計算そのものではないが、訪問実績、入金確認、請求確認と関連するため、月次確認時にあわせて見る。

## 事前確認

- `訪問実績` が最新である。
- `予定・実績照合` を更新し、未実施、予定外、不完全データを確認する。
- スタッフマスタに必要な給与情報が入っている。
- 振込先登録状況が `未登録` または `要確認` のスタッフがいないか確認する。
- 受取人名、銀行名、支店番号、預金種目、口座番号を確認する。

## 受取人名の注意

銀行側で登録されている受取人名と、振込CSV側の受取人名が異なると、振込エラー、返戻、金融機関側の確認対象になる可能性がある。

運用:

- 口座名義カナは半角カナへ変換する。
- 口座登録フォーム回答とスタッフマスタ既存値が食い違う場合は、要確認にする。
- 給与振込CSV作成前に、要確認のスタッフを確認する。
- 実際の振込エラー、組戻し、手数料、再振込は銀行の仕様に従う。
- 必要時はGMOあおぞらネット銀行の最新案内を確認する。

## 主なメニュー

```text
📌 自費リハ管理 -> 📅 予定・実績照合を更新
📌 自費リハ管理 -> 🎫 回数券を更新
📌 自費リハ管理 -> 💰 給与集計だけ更新
📌 自費リハ管理 -> 📄 給与明細PDF・振込CSVを作成
📌 自費リハ管理 -> 📁 給与明細PDFをスタッフフォルダへ移動
📌 自費リハ管理 -> 🏦 口座登録フォームをスタッフマスタへ取込
📌 自費リハ管理 -> 🔤 カナから口座名義を補完
```

## 確認項目

- 給与集計にテスト利用者が含まれていない。
- 給与0円のスタッフ明細が作成されていない。
- 給与明細PDFが該当スタッフフォルダへ入っている。
- GMO振込CSVが確定フォルダへ移動されている。
- 口座情報が未登録・要確認のスタッフが給与振込対象に混ざっていない。
- 回数券管理で、未入金額・不足額・直近入金実績に不自然な点がない。
