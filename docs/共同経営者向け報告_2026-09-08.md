# 共同経営者向け報告 2026-09-08

## 概要

自費リハ管理システムについて、管理者LIFF、Googleスプレッドシート、GAS、GitHub連携まわりの整備を進めた。主要な本番反映とGitHubでの履歴管理は完了している。

## 完了したこと

1. 管理者LIFFの改善

管理者画面から、スタッフと利用者の紐づけ後に「担当開始準備パネル」が表示されるようにした。担当開始時に必要な確認を、管理者画面上で進めやすくしている。

2. スタッフ向け銀行登録フォーム案内

管理者LIFFから、担当スタッフへ銀行登録フォームの案内を送れるボタンを追加した。LINE送信ログとLIFF操作ログにも記録される。

3. テスト利用者の整理

本番スプレッドシート上に残っていた「テスト利用者」とスタッフの紐づけを削除した。今後誤って本番に再作成されないよう、GAS側で自動追加を無効化した。

4. GAS本番反映

ローカル `clasp` とGitHub Actionsの両方でGASデプロイを確認した。`CLASPRC_JSON` 更新後は、push後にGitHub Actionsで自動デプロイできる状態に戻っている。

5. GitHub履歴管理の整備

`reha1` 本体リポジトリと、システム台帳リポジトリをGitHubへ同期した。作業記録、手順書、引き継ぎ情報もGitHub上で管理できる状態にしている。

6. 作業記録・手順書・スキルの更新

複数チャットで作業しても状況を引き継げるように、これまでの作業経緯、現在の状態、運用ルール、GitHub認証手順、GASデプロイ状況をドキュメントとCodexスキルに反映した。

## 現在の状態

- 管理者LIFF、GAS本番反映、GitHub Actions自動デプロイは動作確認済み。
- 本番環境からテスト利用者は削除済みで、再作成防止も反映済み。
- GitHub push時の認証はmacOS Keychainに保存済みで、通常は毎回tokenを入力しない。
- GitHub Actions画面のNode.js 20警告は現時点では失敗原因ではなく、デプロイ自体は成功している。
